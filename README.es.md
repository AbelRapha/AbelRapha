# ¡Hola, soy Abel! 👋

Ingeniero de datos y analytics, enfocado en productos de IA. Estudio Ingeniería de Transporte en la UNICAMP y trabajo con datos desde 2021.

- 🏥 Actualmente trabajo en Hapvida, donde modelo datos clínicos y construyo paneles que la operación y la auditoría médica usan para decidir.
- 🧮 Me gustan los problemas de investigación operativa, como el ruteo, la asignación de recursos y la planificación.
- 🛠️ Construyo herramientas para problemas reales, como [Premius](https://app.usepremius.com), una plataforma de gestión de cartera para corredores de seguros.
- 🎥 Enseño programación y datos en el canal [Descomplicando Dados](https://www.youtube.com/channel/UCwA0jaKFfgyOUrWx5CN_Nzw) (en portugués).

## Qué hago

- **Ingeniería de datos:** pipelines, ETL y modelado en Oracle, Databricks y BigQuery
- **BI y analytics:** paneles en Power BI y Tableau
- **IA aplicada:** LLM, OCR, automatización y agentes
- **Optimización:** investigación operativa con Python
